# Example Files

Starter templates for new stations:

- [dummy.vnc](dummy.vnc)
- [dummy.json](dummy.json)
- [TightVNC-Viewer-Help.txt](TightVNC-Viewer-Help.txt)

Typical usage:

1. Copy `dummy.vnc` into `vnc-view/` or `vnc-control/`.
2. Copy `dummy.json` beside the matching connection name if you want custom labels or placement defaults.
